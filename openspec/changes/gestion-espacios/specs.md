# Spec Delta

## Purpose
Permite registrar y administrar espacios académicos (laboratorios, auditorios y salas de cómputo).

## ADDED Requirements

### Requirement: Registrar espacio académico
El sistema SHALL permitir registrar espacios con identificador único, nombre, capacidad y ubicación.

#### Scenario: Registro exitoso
- **WHEN** el usuario ingresa datos válidos
- **THEN** el sistema guarda el espacio y lo muestra en la lista
